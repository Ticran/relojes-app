# Relojes App

Aplicación web para administrar el inventario de un negocio de relojes y accesorios.

## Funcionalidades previstas

- Gestión de productos, precios y stock.
- Catálogo público de productos.
- Creación y administración de pedidos.
- Registro de ventas e historial de inventario.
- Panel privado para el vendedor.

## Tecnologías

- Frontend: React + Vite.
- Backend: Node.js + Express.
- Base de datos: PostgreSQL.
- Control de versiones: Git + GitHub.
